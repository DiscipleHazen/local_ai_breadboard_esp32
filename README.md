This is a personal learning project, I wanted to learn how to use a breadboard, microcontroller, running a local LLM, and transmitting data over a network. AI helped me generate the code for these projects; it was the guide to my ideas here. 

The microcontroller is the Arduino Nano ESP32.
The AI is running locally on Ollama.
The I2S protocol is used to communicate to the modules from the microcontroller.
The displays on the breadboard are the SSD1306 oled .96 inch displays.
The microphone is the INMP441 MEMS omnidirectional Microphone module.
The amplifier is the MAX98357 I2S 3W.
The speakers are 3 Watts 4 Ohms.

Of course, it's all connected with a bunch of male-to-male jumper wires.

The GPU running the model was a RTX 5070 Ti

It was very fun to learn how to solder, the basics of network programming, the basics of microcontrollers and modules, and running local AI models.
